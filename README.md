# Ouvertures-Echecs

Site de référence pour explorer les principales ouvertures d'échecs, avec un hub d'accueil, des fiches détaillées par ouverture, des idées stratégiques, des variantes, et des diagrammes visuels de position de base.

## Fonctionnalités
- Catalogue d'ouvertures avec recherche rapide
- Fiches complètes par ouverture
- Résumé stratégique et idée principale
- Théorie moderne avec lignes de jeu et évaluations
- Variantes détaillées
- Diagrammes de position de base pour visualiser immédiatement la structure de chaque ouverture

## Stack
- HTML
- CSS
- JavaScript vanilla

## Démarrage local
1. Ouvrir le projet dans le navigateur via un serveur local
2. Exemple :
   ```bash
   python3 -m http.server 3000
   ```
3. Puis ouvrir : http://localhost:3000

## Objectif du projet
Créer une petite encyclopédie visuelle et pédagogique sur les ouvertures d'échecs, avec une logique claire: découvrir une ouverture, comprendre son idée, puis entrer dans la théorie et les variantes.
